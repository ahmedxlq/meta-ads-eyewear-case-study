# Meta Ads Case Study: Vision Jeddah Eyewear

## 📌 Project Overview
A simulated Meta Ads campaign for a local Jeddah-based eyewear brand. The goal was to drive direct e-commerce sales using a bilingual (Arabic/English) strategy.

*(Click the "Marketing.pdf" file above to view the full slide deck).*

## 🎯 Strategy & Targeting
- **Objective:** Sales (Website Purchases)
- **Location:** Jeddah, Saudi Arabia
- **Demographics:** Men & Women, Ages 18–35
- **Interests:** Fashion, Eyewear, Luxury Brands, Shopping
- **Placements:** Instagram Feed & Stories (Advantage+)

## 📊 Budget & Forecasting
- **Monthly Budget:** $500
- **Estimated Cost Per Click (CPC):** $0.50
- **Projected Clicks:** 1,000
- **Conversion Rate:** 2%
- **Projected Orders:** 20
- **Target Cost Per Acquisition (CPA):** $25

## 🛠️ Tracking & Optimization
If this campaign went live, I would install the Meta Pixel to track 'Add to Cart' and 'Purchase' events. This allows the algorithm to optimize for actual buyers rather than just clicks.
